# Citing plotviz

If you use plotviz in your work, for instance to make the charts of a paper, a report or a thesis, please cite it:

> Cachim, P. (2026). *pcachim/plotviz: desktop chart editor for scientists, engineers, and analysts* [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23378412

The DOI above always leads to the most recent release. The page it opens also lists the DOI of each earlier version, in case you want to cite the exact one you used.

The licence of the program applies to the program only; the charts you make with it, and your data, are yours (see [Licenses](licenses.md)).
